# Fase 3 Producto - Experiencia V1

**Pregunta central:** Como se siente usar Manzana?  
**Estado:** V1.4 - Fase 3 V1 cerrada; sincronizada con Fase 6 visual V1  
**Ultima actualizacion:** 31 de mayo, 2026

---

## 1. Proposito

Fase 2 define que existe en Manzana V1. Fase 3 define como se vive.

Esta fase evita que WhatsApp, Dashboard, IA, insights, deudas, pagos que vienen y recordatorios se implementen como piezas correctas pero emocionalmente desconectadas.

Principio:

> Manzana no compite por tener mas funciones. Compite por hacer que el usuario se sienta entendido, con mas claridad y con menos friccion.

## 3. Estado De Cierre

Fase 3 V1 queda cerrada para implementacion inicial cuando se usen los documentos `10` a `18` como contrato de experiencia.

Estado actual:

- No quedan documentos V1 pendientes dentro de Fase 3.
- Shareables no bloquea V1; queda fuera hasta decision posterior y no tiene documento activo.
- Los pantallazos reales del Dashboard quedan pendientes como trabajo de prototipo, no como hueco de especificacion.
- La identidad visual, design system y handoff visual viven en Fase 6; Fase 3 conserva el contrato de experiencia, tono y estructura.
- Si se actualiza una decision de producto, debe reflejarse en el documento especifico y luego en este indice.

## 6. Decisiones ya tomadas

- WhatsApp es la entrada principal de captura y conversacion.
- Dashboard es revision, claridad, control y confianza.
- El dinero se protege con motores deterministicos.
- IA entiende lenguaje, intencion, contexto y explica.
- `Insights` se sienten como descubrimientos.
- `Recurrentes` se muestran como **Pagos que vienen**.
- `Nudges` se muestran como **Recordatorios** o **Avisos**.
- Modo discreto aplica a mensajes proactivos y datos sensibles.
- Uso parcial es valido.
- Datos imperfectos son aceptados si generan claridad segura.
- El wow no es espectaculo; es autodescubrimiento amable.

## 7. Criterio de avance

Fase 3 esta lista cuando un implementador pueda responder sin inventar:

- Como habla Manzana?
- Que muestra primero?
- Que no debe decir nunca?
- Como se siente corregir un error?
- Como se ve un usuario nuevo?
- Como se ve un usuario con datos incompletos?
- Que pasa cuando el usuario abandona?
- Como se evita que recordatorios molesten?
- Como se ve el primer wow?
- Como se conectan WhatsApp y Dashboard?
- Como se traduce esa experiencia a una identidad visual consistente?
